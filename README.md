# Full Stack To-Do App

A full-stack web application for managing personal tasks, built with **React**, **Node.js**, **Express**, **MongoDB**, and **JWT Authentication**.

---

## Features

- User Registration & Login (JWT-based)
- Create, Read, Update, Delete tasks
- Tasks scoped to each user only
- React Frontend with Context API
- Axios for API communication
- MongoDB with Mongoose schema models
- Clean, minimal UI (custom styled)

---


## ⚙Setup Instructions

### 1. Clone the Repository

git clone https://github.com/Surya-3-tarun/todo.git
cd todo

### 2. Setup Backend
   
cd backend
npm install
cp .env.example .env  # or manually create .env
npm run dev

### 3. Setup Frontend
cd ../frontend
npm install
npm start
